# Page de Lukas

Petit site web personnel réalisé dans le cadre d'une formation de développement.

## Description

Une page unique, en français, où je me présente et où je partage quelques remarques sur Git. Le site est un projet d'apprentissage : il sert à pratiquer HTML et CSS.

## Contenu du projet

```
.
├── index.html   # Structure de la page
├── style.css    # Mise en forme
└── README.md    # Ce fichier
```

## Structure de la page

- Un titre principal (`h1`)
- Un menu de navigation (`nav`, pour l'instant un simple texte « Menu »)
- Quelques paragraphes de présentation
- Une section « À propos » (`section`, encore à compléter)
- Un pied de page (`footer`)

## Utilisation

Aucune installation ni dépendance n'est nécessaire. Il suffit d'ouvrir `index.html` dans un navigateur :

```bash
git clone https://github.com/Sirmetana/my-site.git
cd my-site
# puis ouvrir index.html dans votre navigateur
```
